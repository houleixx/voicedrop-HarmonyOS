# 图片生成等待与加载恢复

仅修改客户端图片生命周期，不修改后端协议、文字生成、编辑队列、图片 marker 或上传格式。

- 编辑更新引入的新图片记录为生成图，显示制作中并轮询。
- 按完整的 owner scope + 图片 key 保存生成标记、首次等待时间和已显示标记；不存 Token 或指令正文。
- 退出重进、页面重建保留等待期限；无来源记录的图片使用“正在获取图片”，仍有最多 5 分钟恢复窗口。
- 已显示过的普通图片读取失败，自动重试窗口为 15 秒。生成图/未知图的失败请求间隔约 3 秒，最多 5 分钟。
- 超时后再进入仍尝试读取已晚到的结果；手动重试重置等待时间，仅重新加载，不再次提交生成任务。
- Android 下载并解码 Bitmap 后才结束等待；鸿蒙收到 Image 的完成回调后才结束等待，解码失败沿用原期限，退出后的旧回调被忽略。
- 每张图独立计时，图片等待不会阻止正文更新。后端没有任务状态时无法准确判断生成是否失败，使用“暂时无法显示”。

## 设备回归步骤

1. 生成公众号题图、解释图和自定义多张插画，检查缺图阶段等待、出图后真实比例显示。
2. 对已有图片应用卡通、水彩、素描、油画等指令，检查新 key 正常进入制作等待。
3. 生成过程中退出重进、切换版本或改写正文：文字正常更新；等待时间不反复重置。
4. 断网后恢复，分别测试已显示过的旧图和首次打开的未知图片；前者显示普通加载，后者显示中性获取提示。
5. 模拟已下载文件损坏，确认恢复重试直到显示成功或达到期限，不能无限等待。
6. 超时点击重试，检查没有新增文章编辑/绘图请求；生成超过期限后重进，仍能读取已完成图片。
7. 切换账号、快速离开页面，确认不复用其他 owner 的状态，旧请求不覆盖当前图片。

真机生成、网络故障与长时间等待仍需按上述步骤验证；构建和本地状态测试不能替代平台显示验证。
