# Android → HarmonyOS 功能迁移清单

源项目：`voicedrop-android`

更新时间：2026-07-22

## 已接入并通过 ArkTS 编译

- HarmonyOS Stage 模型工程、`com.baixingai.voicedrop.hm` 包名、手机/平板/2in1 设备声明。
- 启动页、我的录音、VD 社区、文章详情、设置、账号、文风、公众号、用量、关于和隐私页面。
- 麦克风、相机、相册、网络权限；首次启动隐私同意门禁。
- AAC/M4A 原生录音、最终 VoiceDrop 文件名、上传、tags sidecar、触发文章挖掘、本地删除偏好。
- `/recordings` 与 `/list` 降级加载、录音状态、文章 v1/v2 JSON、多文章切换、图片 marker 渲染。
- 文章公开分享链接、公众号草稿发布、文字修改队列、原录音播放与进度拖动。
- 文章版本历史、撤销/重做、重新生成，以及带确认的录音/文章/字幕/标签整条删除。
- 文章标题/正文直接编辑保存、完整版本列表浏览与任意历史版本切换。
- 相册多选与系统相机入口、图片上传、通过编辑会话插入文章。
- 匿名 Token 持久化与导入、微信 session 保存/退出基础能力，以及服务端永久删除账户成功后清理本机身份/待发送队列并创建全新匿名空间。
- 写作文风、姓名、文风历史切换、2–3 个多文风选择和公众号配置。
- 完整算力页：实际 `suanli/spent_suanli` 余额协议、约可成文篇数、累计获赠/已用、来源/花费汇总和可分页加载的明细流水。
- VD 社区 feed/list 降级、社区正文详情、回复列表、点赞、举报、社区发布/隐藏和首次发布公约门禁。
- 社区点赞状态即时同步、按作者本地屏蔽及设置页解除屏蔽管理。
- 社区语音回复待发布状态持久化；回复录音成文后自动关联原帖发布。
- `/agent/status`、`/agent/edit`、`/agent/asr` 和 `/agent/realtime/relay?fmt=pcmu` WebSocket 客户端。
- 完整提示词树缓存/原始引用编码、新增/编辑/删除/分组内与顶层排序、恢复默认、7 位分享码预览/导入和自定义提示词分享。
- 文章段落与图片长按快捷菜单，支持 `{{LINE}}`、`{{QUOTE}}`、`{{KEY}}` 模板替换并发送编辑指令。
- 首页 `/agent/command` 图库文字指令、当前列表行号引用、服务端状态/回复/更新响应及危险操作确认/取消。
- 火山 ASR 二进制协议（gzip 帧、序列号和末帧）、16 kHz 单声道 PCM 麦克风采集，以及首页图库指令和文章修改输入框的语音听写入口；文章修改支持按住采集、松开发送、上滑取消。
- HarmonyOS 深链和系统分享接收声明；外部文字分享进入文风数据集。
- 冷启动/前台 `Want` 分享接收；文本、网页、UTF-8/RTF 文档收集，音频上传成文，多图片 JPEG 转码上传并创建静音成文任务。
- 设置页完整 ZIP 数据导出：云端音频、文章离线 HTML、SRT 字幕、文章图片与总索引，并通过系统文档选择器保存。
- 6+4 设备配对 UI、`/agent/link` REST/WebSocket 流程、老设备待确认请求恢复，以及 X25519 + HKDF-SHA256 + AES-256-GCM 匿名 Token 端到端迁移实现。
- 录音中系统拍照/相册选择、横向照片胶片、单张删除，以及 JPEG 私有目录持久化和失败跨启动重试。
- 文章追问卡片、跳过/已回答状态同步，以及文字或 ASR 回答织入正文。
- 文章指定历史文风重写，通过编辑 WebSocket 接收 `preview-delta/reset/done` 并实时合并展示新稿；已生成文风直接切换历史版本。
- `/agent/command` 图库指令本地持久队列、WebSocket 断线重连/重发、服务端 snapshot 对账和终态清理。
- 文章可视行号覆盖层，与长按快捷提示词的 `{{LINE}}` 定位规则一致。
- `voicedrop://` 的录音列表、社区、设置、用量、开始录音、指定文章、提示词导入和设备配对路由，以及首页/提示词 HTTPS 链接。
- 提示词 `GET /prompt-shares` 分享状态、开启/取消分享、7 位码与链接复制管理面板。
- 系统分享内容预览/确认面板：音频、多图片与文字/文档先展示用途和摘要，只有明确确认后才上传或收进文风数据集，取消不会重复导入。
- 快捷提示词支持通过专用“≡”手柄拖动排序，分组和组内提示词分别保持顺序；上下按钮继续作为精确操作兜底。
- 启动时每日一次与设置页手动更新检查；仅识别专用 HarmonyOS Release 中已签名的 HAP，支持版本比较、忽略版本和打开发布页交由系统安装，绝不误装 Android APK。发布仓库尚未建立时安全静默降级。
- 设置页服务端 `CONFIG.json` 自动分享到 VD 社区开关，以及 `/agent/referral/link` 专属邀请链接与 HarmonyOS 系统分享面板。
- 首次启动 24 小时邀请归因：`hello`、隐私同意后的剪贴板邀请链接，以及 `voicedrop://i/…`、`voicedrop.cn/i/…`、`jianshuo.dev/voicedrop/i/…` 深链均调用 `/agent/referral/claim`，终态只处理一次。
- 通用 6–16 位文章短链通过 `/files/api/link/{id}` 解析：本人文章进入可编辑详情、社区帖进入社区详情，非本人私有分享使用原生只读多文章/图片阅读页，失败才回退网页。
- 社区分享遇到微信未登录/会话失效时保存 15 分钟待发送项；session 恢复后自动续发文章或回复并清理终态。
- 录音页实时 AI 采访：16 kHz PCM 转 8 kHz μ-law 上行、24 kHz PCM 流式语音播放、AI 回答期间半双工静音、输入缓冲清理、指数退避重连和额度类错误安全降级。
- 实时 AI 采访识别 WebSocket `1013` 关闭码及额度、计费、账号停用错误；进入“暂不可用”终态后停止音频上行、播放和自动重连，但主录音继续。
- 社区详情“投币/算力馈赠”：读取本人投币状态与次数、提交投币，并处理重复、自己内容、当日池耗尽和需登录等服务端状态。
- HarmonyOS 静态快捷方式“记一条”，直接携带 `voicedrop://record` 启动录音页，与 Android Launcher Shortcut 行为对应。
- 文章“小红书”分享：调用 `/agent/xhs-pack` 生成标题、正文和标签，复制完整文案并打开 HarmonyOS 系统分享面板。
- 公众号凭据先调用 `/wechat-validate` 服务端验证再保存，并针对 IP 白名单、无效 AppID/AppSecret 给出明确提示。
- 快捷提示词社区市场：热门/最新/文字/配图筛选、作者与导入次数、示例详情、重复状态识别和一键导入。
- 提示词市场详情对齐 Android 最新实现：展示提示词全文、适用范围、导入次数与示例，全文按分享码异步加载并处理失败状态。
- 文章文字/图片长按菜单保留提示词分组层级；系统项固定展示、自建/导入项在超高时独立滚动，子菜单提供固定返回入口，只有分组显示右箭头。
- 提示词来源在解码与菜单过滤中完整保留；缺失来源的 `sys_` 项按系统项处理，其余按自建项处理，新建提示词不再误标为“已自定义”。
- 微信 JWT 到期/损坏时自动退出；切换到微信云端空间前保留匿名 Token，主动退出或会话失效后恢复原匿名空间。
- VD 社区“推荐 / 最新 / 回应”筛选：消费 `/reco/feed` 的推荐顺序，回应页只展示回复内容，统一 feed 不可用时继续从社区源安全降级。
- 旧社区列表降级路径补齐 `/reco/rank`：恢复推荐顺序、点赞状态/数量与本地计算的回复数，不依赖统一 feed 才能完整显示。
- 社区提示词帖子：feed 徽标、分享码、说明正文、适用范围和一键收下；提示词帖子不出现语音回复入口。
- 社区帖子封面图、回应原文跳转、系统分享链接、本人帖子取消分享，以及回复详情数据规范化。
- 账号页展示并可复制匿名账号 ID/脱敏 Token，显示录音和文章数量；关于页补齐社区公约、已屏蔽用户、支持邮箱和完整入口。
- 离线完整隐私政策：覆盖录音/文章/图片/账号/社区数据场景、权限、委托处理、保存与安全、用户权利、未成年人保护和联系方式。
- 腾讯官方 HarmonyOS OpenSDK `@tencent/wechat_open_sdk` 1.0.19：微信安装检测、`snsapi_userinfo` 授权、EntryAbility 回调校验、`/auth/wechat` 换取 session、同空间直接登录、异空间确认切换和退出后恢复匿名空间。
- 录音静音保护：周期采集 `AVRecorder` 最大振幅，低峰值录音上传前要求确认；丢弃时同步清理录音、照片和回复待办。
- 首页动态标签筛选，以及 `voicedrop://record?tag=…` 指定新录音标签；标签以 `.tags` sidecar 随录音上传。
- 上传可靠性与恢复：M4A `moov`/大小校验、三次退避重试、本地标签 sidecar、上传成功后删除或移入 `uploaded`，启动时展示并续传遗留录音。
- `/recordings` 轻量列表后台补取标题/标签；旧 `/list` 根据对象键推导成文、空录音和标签状态，兼容两代服务端协议。
- Token 导入和设备配对成功后立即切换并刷新新账号空间，不再停留在旧列表状态。
- 文章正文兼容旧顶层 `title/body` 和新版多文章结构；渲染前清除 HTML 元数据注释，图片 marker、风格版本、首图、分享文本与可视行号均按 Android/iOS 语义解析。
- 录音命名对齐 5/9/12/14/18/20/23 点时段边界、秒数四舍五入及跨端位置解析；照片键统一为 `offset-三位随机码.jpg`。
- `voicedrop://prompt-import?code=…`、官网网页回退和 `jianshuo.dev`/`www.jianshuo.dev` 旧域名入口完整路由；7 位数字导入码与 8 位普通分享 ID 保持区分。
- 文章系统分享发送完整多文章正文加公开链接，系统面板失败时复制同一内容；前台恢复在顶层页静默刷新录音/社区，详情页保持稳定。
- 所有 JSON、上传和二进制下载请求统一发送 `X-VD-Platform: harmonyos`，供服务端平台策略、灰度和日志识别。
- 隐私同意采用真正的业务启动门禁：同意前不创建身份、不联网、不续传、不解析分享、不初始化音频或 WebSocket；强制选择层可展开阅读完整政策，拒绝直接退出。
- 录音启动/停止加单次状态门与“正在保存”禁用态，避免异步释放时重复点击；播放下载加 loading 门，完成/错误自动释放播放器并复位进度。
- 文章编辑消息补齐 `type: instruct`、结构化文本/图片 `anchor` 和提示词 `itemId`，快捷操作既保留自然语言模板也提供精确服务端定位。
- 状态与文章编辑 WebSocket 增加断线重连和旧实例回调隔离；图库指令继续使用其持久队列重连，听写/采访由专用会话管理。
- 图库危险操作的待确认卡、确认/取消控制均本地持久化；重连时恢复提示并重发控制，收到 reply/error/updated 或 snapshot 终态后对账清理。
- `/whoami` owner scope 按账号缓存；本人文章、社区文章和公开分享统一以 owner scope 拼接相对图片键，并兼容 `[[photo:1]]` 旧数字标记；公共源对齐 `https://voicedrop.cn/photo/{fullKey}`，避免跨账号图片 404。

## 下一阶段必须补齐（目标仍是全部复刻）

- 真机 ASR 验证，以及确认具体 HarmonyOS 机型允许 M4A `AVRecorder` 与采访 `AudioCapturer` 同时采集；不允许时需以原生共享 PCM 录音后端替换双采集架构。
- 微信开放平台登记 HarmonyOS 的 bundle/identifier/发布签名并进行真机授权验收；设备配对的 HarmonyOS 真机与 Android/iOS 互操作验证。
- 建立 HarmonyOS Release 仓库并发布已签名 HAP；Android 的友盟统计仅在注入外部 AppKey 时启用，本仓库没有该密钥，当前两端均安全停用。HarmonyOS 服务卡片不属于 Android 原版复刻范围。
- PDF、DOC/DOCX 结构化抽取属于后续增强；Android 原版同样只收集纯文本/UTF-8/RTF，当前实现已保持一致并拒绝把 PDF/ZIP 二进制误当文字。
- 真机权限/录音/相册/公众号/社区/分享链路验证和已签名 HAP。
